Dataset Generator

Use the CLI to generate synthetic market + order datasets for replay and back-testing.

Command: cargo run -- generate-dataset --events 100000 --out data/sim.jsonl

The generator creates a realistic stream of MarketEvent and OrderRequest records in JSONL format. Each order includes optional expected_outcome and scenario_tag fields for confusion-matrix evaluation.

Generated files appear in the Replay tab file selector and can also be used for offline analysis.
